# FlyRank — Ranking Signal Analysis

This repository contains the capstone materials for the FlyRank ranking signal analysis project.

Contents
- `notebooks/`: setup and EDA notebooks
- `capstone/`: capstone starter notebook
- `docs/`: deployed paper and rendered notebook pages
- `submission/paper_url.txt`: one line with the live paper URL

Deployment
- GitHub Pages serves the paper from the `gh-pages` branch.
- The live site should contain the paper and notebook links.

Data credit
- Built on the FlyRank ML Internship dataset — https://flyrank.ai
