# FlyRank — Ranking Signal Analysis (Scaffold)

This repository is a scaffold for the FlyRank capstone: Ranking Signal Analysis.

Contents
- notebooks/: weekly assignment notebooks and capstone notebooks
- capstone/: capstone-specific materials and starter notebook
- submission/paper_url.txt: REQUIRED — one line with the final deployed paper URL

How to use
1. Download the ZIP distributed with this scaffold and extract it locally.
2. Copy or move these files into your cloned GitHub repo (see push commands below).
3. Complete notebooks under notebooks/ and capstone/, then update submission/paper_url.txt with the deployed paper URL.
